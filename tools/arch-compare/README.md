# arch-compare

Measurement scripts for `docs/encoding-work/arch-comparison.md`: the static size of the 841-file corpus of `docs/encoding-work/integration.md`
for pdp64 (pcc), pcc amd64 and i386, and GCC and clang for RISC-V (rv64gc, rv64g), AArch64, x86-64, i386, Arm and MIPS64 at
-O0, -O1, -O2, -O3 and -Os.  Not a GNU-packaged project: a folder of scripts.

## What has to exist

* the pdp64 tools of the repository: `build/as64` (`tools/build-as64.sh`);
* the pcc tree: `PCCENC=<work>/pcc` (`build-ccoms.sh` builds from a scratch copy and leaves the tree alone); the numbers of pdp64/32 and pdp64/16 in `docs/encoding-work/arch-data` were measured with the tools of the git tag `pre-single-cpu`;
* the corpora under `<work>/corpora` (with `sysroot/<arch>/include`, the musl headers) and the v7unix-toolchain repository
  (`<work>/facetlang/pdp11/v7unix-toolchain`, `TOOLCHAIN=` to move it): `prep.py` imports its `tools/corpus.py` for the per-corpus include directories and defines,
  exactly as `tools/pdp64size.py` does;
* `clang` (21) with the RISC-V, AArch64, ARM, MIPS and x86 targets, `llvm-objdump-21`, host `gcc` (x86-64 and -m32);
* No GCC rows (dropped); the diagnosis probes of `diag-riscv-backend.sh` need GNU `as` and `ld` for RISC-V (binutils 2.43.1 configured `--target=riscv64-unknown-elf`) in `WORK/gccx/prefix/bin`.

## Files

| file | what |
|---|---|
| `fair.txt` | the 841 files: corpus, path under `<work>/corpora` (the `fair` set of `tools/pdp64size.py`: what the aarch64, amd64 and i386 builds of corpus.py all compile with `ours -O`, from `/tmp/co-final/results.jsonl`) |
| `prep.py ARCH OUT` | preprocess the 841 files for ARCH (`aarch64` is the text pdp64 gets) into `OUT/NNN.i`, `OUT/index.tsv` |
| `build-ccoms.sh TREE DIR` | build ccom for pdp64, amd64, i386 and (for the diagnosis) riscv64 from scratch copies of TREE |
| `pdp64-static.py` | `ccom`, `as64 --stats`: instructions, instruction bytes and `.text` bytes per file |
| `pcc-static.py` | the same for a pcc back end whose output is assembled by the host assembler (amd64, i386) |
| `ref-static.py`, `run-refs.py` | GCC and clang objects for the matrix of architectures and levels |
| `objstat.py` | instruction count, instruction bytes, padding and `.text` size of an object, from `llvm-objdump -d` |
| `summarize.py WORK OUT` | merge: `static-wide.csv`, `static-summary.md` (the tables of the report) |
| `pcc-compile.py` | compile the preprocessed corpus with a given ccom and list the failures (used for the RISC-V back end diagnosis) |
| `diag-riscv-backend.sh WORK` | the probes of the report's section on pcc's RISC-V back end |
| `boundscan.py` | the census of bounds checks: `-fsanitize=bounds` IR of the corpus, each check classified (one unsigned compare against a constant or a variable bound, an index with an offset that may wrap, merged, signed), `bounds-price.py` prices the forms (cbhis, cmp+trapcc, CHK, CHK2, LoongArch's ASRT) on the sites; `docs/encoding-work/loongarch.md` |
| `la-mnemonics.py`, `la-summary.py` | the instructions a compiler uses on the corpus by mnemonic; the LoongArch64 tables of `docs/encoding-work/loongarch.md` (LoongArch needs a musl sysroot made with `make install-headers`, and `SYSROOTS=` for `prep.py`) |
| `adacheck.py`, `corpus-ada.txt` | the Ada corpus (the GNAT run-time library bodies) compiled with GNAT's default checks and with `-gnatp`: the price of Ada's checks, the check sites by kind, the cold failure blocks |
| `rustcheck.py`, `mkrustcorpus.sh`, `corpus-rust.txt` | the Rust corpus (parsers generated by hbnf) compiled by rustc with overflow checks on, and its IR for AArch64, RISC-V and LoongArch by clang: check sites by kind and the cold blocks; `docs/encoding-work/bounds-check-isas.md` |
| `vecscan.py` | dav1d's pixel kernels (the C of a meson build with `enable_asm=false`) compiled for AVX2, AArch64, RISC-V vector and LoongArch LASX with and without the vectorizer: sizes, the loops vectorized and why the others were not, and the shape of each vectorized loop body (map, reduce, shuffle, masked, gather) |
| `handkernels.py` | dav1d's hand-written NEON and RISC-V vector assembly (`src/arm/64`, `src/riscv/64`) assembled and counted per exported function |
| `vecwin.py` | the script that looks in pdp64 assembly for the loops where a `vec` prefix would win: innermost loops classified as map, reduce, fill, branch or call, with the shape of each |
| `vecbench.py`, `handasm.py`, `vecforms.py` | the kernels of `vec-forms.md`: clang's vectorized and scalar builds for AVX2, AVX-512, NEON, SVE, RISC-V V and LoongArch LASX (instructions, main loop, vectorization width); the instructions of hand-written assembly functions in object files (NASM x86, NEON, RVV); the tables joined with pcc's scalar code and the hand-written `vec` forms |
| `gemmloops.py` | the main loop of OpenBLAS's single-precision GEMM kernels, assembled or compiled per instruction set: instructions, multiply-adds, loads, instructions per multiply-add (`gemm-forms.md`) |
| `checksites.py` | the guard of each run-time check in the assembly of `ccom -xchecks`: the branch, immediate or register bound, the sizes of the immediates (`check-instructions.md`) |
| `costbenefit.py` | the kernels of games and of inference (`arch-data/vec-forms/games/`): pcc's scalar code, the hand-written vec forms and clang's vectorization on five instruction sets (`vec-cost-benefit.md`) |
| `Makefile` | `make WORK=/scratch/dir` runs everything in order |

## Commands

    make WORK=/scratch/rv prep ccoms          # preprocess, build the compilers
    make WORK=/scratch/rv pdp64 pccx86        # pdp64, pcc amd64, i386 (two flag sets each)
    python3 run-refs.py /scratch/rv           # the GCC/clang matrix (about 40 configurations, each 1 to 4 minutes on two idle cores)
    python3 summarize.py /scratch/rv ../../docs/encoding-work/arch-data

Each `static.csv` has one row per file: `file,status,ins,ibytes,text,data_in_text,pad_ins,pad_bytes,msg` (`pdp64-static.py` has `cbcc_expanded` in
place of the padding columns, and `ins`, `ibytes` come from the assembler's statistics line).
