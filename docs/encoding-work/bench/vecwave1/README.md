# The accumulator strip and the wave-1 removals: the measurements behind `vector-strip-and-wave1-measured.md`

Written 2026-11-27. Nothing here changes a tracked file; all builds were made in scratch copies.

* `driver.c`, `kern_only.c`: seven kernels in plain C (dense: `k_sgemm` 16x16x64 f32, `k_q8dot` 4096 bytes, `k_q8matvec` 64x256, `k_conv1d` 2048 x 8 taps, `k_conv3x3` 34x34; sparse: `k_spmv` CSR 256 rows with a gather of `x[col]`, `k_lut256` a 256-entry byte table over 4096 bytes). `driver.c` fills the data, hashes every output buffer (the same cost in every run, so it cancels), prints the hash.
* `run.py KERNEL VARIANT STRIP`: builds the driver with the kernel (`scalar` = llc -O2; `lv` = opt -O2 for pdp64 with LoopVectorize, vector loops lowered to `vec` blocks; a `.s` path = a hand-written kernel) and runs the **current** `sim64 -V -P -S STRIP --vport=16 --vcommit=1`; the cost is the run minus the run with no kernel. Needs `TOOLS=dir` holding `as64 ld64 sim64 llc opt` (from `build/` and `../llvm-build-22/bin`) and `clang`.
* `hand/`: `k_ukr.acc.s` (the 8x4 accumulator micro-kernel, a copy of the repository's, `movq` written `mov`), `k_q8dot.vdacc.s` (copy), `k_q8dot.acc.s` (vdot into an accumulator), `k_conv1d.fir.s`, `k_lut256.vtbl.s` (a 256-byte table by 16 lookups of 16 entries).
* `sweep.py`: runs everything on the current simulator; writes `results/current.json` and `results/current.tsv` (model 1 and model 2 cycles, scalar instructions, strips, output hash: the hashes of the variants of one kernel are equal, so every variant computed the same answer).
* `widths.py`: the micro-kernel under model 1 with the vector issue width as a parameter, the 32-byte-tile alternative, and the cost of packing (`results/widths.txt`).
* `removed/`: the REMOVED words. They exist only in the simulator of commit `fe84570d~1`. Rebuild: `git archive fe84570d~1 | tar -x -C DIR; cd DIR; HBNF=.../hbnf/hbnf HBNF_TEMPLATES=.../hbnf/templates tools/build-sim64.sh` (this builds `build/as64 ld64 sim64`; that tree has no cycle model). `gen.py` writes whole assembly programs (the tile micro-kernel, `gemm.f`, SpMV and a byte lookup with `vldx`), with the data and the expected output; `run_old.sh KIND [param]` assembles, runs and checks the output (`OLD=dir`); every program printed PASS (`results/removed-old-sim.txt`). `model.py` applies **model 1 of `docs/sim64.md`**, as implemented in `check_model()` (it reproduces the simulator's 652 cycles for the q8 dot), to those programs; the three things the old words need and the old simulator does not have are parameters (a tile outer product in one cycle or a row a cycle; a gather lane a cycle or four; the unit's multiply-add array). Those are ASSUMED, not measured: `results/removed-model.txt`.
* Not run: `--timing` (the in-order timing model of `docs/timing-model.md` does not know `vec` blocks), real hardware, caches.
