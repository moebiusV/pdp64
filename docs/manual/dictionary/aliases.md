# Assembler aliases

[← dictionary index](index.md)

A mnemonic that assembles to another instruction (`FNEG.f32` and `FABS.f32` to an instruction with an operand of their own, and a `MOV` before it when the registers differ; `ROL` to `ROR` with the count complemented) or to a short fixed sequence of instructions (`ABS`, `MIN.s64`, `MIN.u64`, `MAX.s64` and `MAX.u64`, which write the scratch register `R12`). One mnemonic is one instruction (section 9.18); the disassembler never prints an alias. A width and kind suffix (`MOV.s8`, `AADD.s32`, `ROR.s32`) is not an alias: it is the notation of the width and kind of one operation. The table ends with the explicit spellings that say what the bare name says (`MOV.s64` is `MOV`), and the spellings where the kind means nothing (`MOV.u8` as a store is `MOV.s8`).
